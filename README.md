# BK프롬 (PWA)

**만든 사람 전용** 앱이에요 (관리자 표시가 없는 휴대폰은 잠금 화면만 보임). 주소: https://bangkeukryul.github.io/bk-prom/

자주 쓰는 **AI 프롬프트 · 결과물**과 **증명사진 · 로고 · 도장 같은 이미지**를 한곳에 모아 두고,
버튼 한 번으로 복사 · 카카오톡 보내기 · 다운로드하는 보관함입니다.

| 구분 | 내용 |
|---|---|
| 프롬프트 · 결과물 | 제목 · 분류 · 프롬프트 · 결과 글 · 결과 사진(여러 장), [📋 복사] 각각, [💬 카톡] [✏️ 수정] [🗑 삭제], ⭐즐겨찾기, 검색, 분류 · 정렬(최신 · 이름 · 많이 쓴 순) |
| 이미지 보관함 | 증명사진 · 로고 · 도장 · 명함 · 배경, 크게 보기, [⬇ 다운로드] [💬 카톡] [📋 이미지 복사] [🪪 BK쇼츠 명함 얼굴로] |
| 백업 · 복원 | 💾 데이터 백업 → JSON 파일(사진 포함) 다운로드 / 📂 데이터 복원 → 합치기 또는 전부 바꾸기 |
| 연결 | BK톡톡 프롬프트 화면의 ‘📥 BK프롬에 저장’ 버튼, BK쇼츠 명함 얼굴 사진 ‘BK프롬에서 가져오기’ |
| 관리자 | 주소 뒤 `?bkadmin` 또는 맨 아래 ‘BK Agent · 비케이’ 7번 → 관리용 주소 · 지금 버전 백업 |

- 저장 위치: 브라우저 IndexedDB (사진도 넉넉하게 저장, 새로고침해도 유지). 어디에도 업로드되지 않아요.
- ⚠️ 휴대폰과 컴퓨터는 서로 자동으로 맞춰지지 않아요. 옮길 때는 백업 파일을 복원하세요.
- 저장소 이름 `bk-prom` · 버전 1 · `items` 구조는 BK톡톡 · BK쇼츠도 함께 쓰므로 바꾸지 않아요.
